# Альберт — .NET Backend Developer

Разрабатываю высоконагруженные backend‑системы на **ASP.NET Core (.NET 8)**, проектирую архитектуру модульных монолитов, работаю с **PostgreSQL + PostGIS**, интегрирую **генеративный ИИ** и создаю сервисы для анализа, голосования и принятия решений.

## 🏗 Текущий проект: Платформа городской среды

Платформа, где граждане голосуют за благоустройство территорий, система автоматически создаёт контракты, подрядчики предлагают решения, а **генеративный ИИ** формирует концепции на основе:

- геоданных площадки,
- картографических слоёв,
- национального контекста,
- архитектурных ограничений.

Модератор получает **пачку лучших идей**, отфильтрованных по реализуемости, бюджету и нормативам.
